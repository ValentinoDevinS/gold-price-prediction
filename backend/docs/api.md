# API Documentation

## Article

GET

/api/v1/ai/articles

Returns paginated articles.

---

POST

/api/v1/ai/articles

Creates article.

---

GET

/api/v1/ai/articles/{uuid}

Returns article.

---

PUT

/api/v1/ai/articles/{uuid}

Updates article.

---

DELETE

/api/v1/ai/articles/{uuid}

Deletes article.
